DATA FLOW
=========

API Requests:
  [Component] → [useQuery/useMutation]
              ↓
           [api.ts]
              ↓
        [axios instance]
              ↓
         [Request Interceptor] (adds Bearer token)
              ↓
         [Backend API]
              ↓
         [Response Interceptor] (handles 401)
              ↓
         [Component State/Cache]

State Management:
  [AuthStore] (Zustand) ←→ [LocalStorage]
  [Query Cache] (React Query) ←→ [Backend]
  [Component State] (useState)

Styling:
  [App.tsx] → [MainLayout] (global layout)
           → [Pages] (page-specific styles)
           → [Components] (component styles)
           → [variables.scss] (design tokens)


ROUTING STRUCTURE
=================

Root Path: /

Public Routes:
  /login                    Login page

Protected Routes (require auth):
  /                         Dashboard
  /equipment                Equipment list
  /equipment/new            Create equipment form
  /equipment/:id            Equipment detail
  /equipment/:id/edit       Edit equipment form
  /projects                 Project list
  /projects/new             Create project (form page)
  /projects/:id             Project detail
  /projects/:id/edit        Edit project (form page)
  /invoices                 Invoice list
  /invoices/new             Create invoice (form page)
  /invoices/:id             Invoice detail
  /invoices/:id/edit        Edit invoice (form page)
  /scanner                  Scanner interface
  /warehouse                Warehouse view
  /settings                 Settings page


KEY PATTERNS USED
=================

1. Custom Hooks:
   - useAuthStore() - Access auth state
   - useQuery() - Data fetching
   - useMutation() - Data mutations
   - useNavigate() - Route navigation
   - useLocation() - Current route info
   - useParams() - Route parameters

2. State Management:
   - Zustand for auth (persistent)
   - React Query for server state
   - useState for UI state

3. Error Handling:
   - Form validation with error messages
   - API error catching with user feedback
   - Loading states with placeholders
   - Empty states with messaging

4. Styling:
   - CSS Modules for component isolation
   - SCSS nesting and variables
   - Responsive design with media queries
   - Dark mode with prefers-color-scheme

5. Data Patterns:
   - Pagination with page/limit params
   - Search filtering with query params
   - Status filters with select
   - Sort with column key + order
