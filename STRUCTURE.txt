Hexagonal Architecture (Per Service)
====================================

{service}/
├── cmd/server/main.go                  Entry point
│
├── internal/                           Internal packages (not exported)
│   ├── domain/                         Business logic
│   │   └── {entity}.go                 Domain models
│   │
│   ├── application/                    Use cases & orchestration
│   │   └── {use_case}.go               Business operations
│   │
│   ├── infrastructure/                 External adapters
│   │   ├── events/                     Event store integration
│   │   └── repositories/               Data persistence
│   │
│   ├── ports/                          Interface definitions
│   │   └── {interface}.go              Contracts
│   │
│   └── adapters/http/                  HTTP implementation
│       └── handlers.go                 HTTP request handlers
│
├── config/
│   └── .env.example                    Configuration template
│
├── migrations/                         Database schema
│   └── V001__init_schema.sql
│
└── go.mod                              Service dependencies

Makefile Targets
================

Development:
  make dev              Start all services locally
  make build            Build all 18 services
  make clean            Remove build artifacts

Testing:
  make test             Run unit tests
  make test-integration Integration tests
  make test-e2e         End-to-end tests

Quality:
  make lint             Run golangci-lint

Docker:
  make docker-build     Build Docker images
  make docker-up        Start containers
  make docker-down      Stop containers

Database:
  make migrate-up       Run migrations
  make migrate-down     Rollback

Other:
  make proto            Protobuf generation (placeholder)
  make help             Show all targets
  make workspace-sync   Sync Go workspace


Quick Start
===========

1. Verify workspace:
   $ go work sync

2. Build all services:
   $ make build

3. Start locally:
   $ make dev

4. Or use Docker:
   $ make docker-up

5. Test:
   $ make test

6. View help:
   $ make help
